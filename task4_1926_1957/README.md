# Task 4 — Valuation Analysis, 1926–1957

This task applies the dividend-based valuation model to the 1926–1957 subperiod of the combined U.S. series from Task 3.

The short sample provides 32 annual valuation observations and 31 regression observations after lagging the cumulative process.

## Main results

| Quantity | Result |
|---|---:|
| Persistence \(b\) | 0.6629 |
| Trend \(c\) | 5.51% |
| 95% ratio interval for \(c\) | 2.72% to 10.13% |
| ADF p-value | 0.0496 |
| Shapiro-Wilk p-value | 0.6603 |
| Ljung-Box p-value for \(Z_t\), lag 10 | 0.6726 |
| Ljung-Box p-value for \(Z_t^2\), lag 10 | 0.8115 |

The confidence interval is substantially wider than in the long historical sample, reflecting the shorter estimation period.
