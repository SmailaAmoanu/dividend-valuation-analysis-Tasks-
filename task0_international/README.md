# Task 0 — International Valuation

Dividend-based valuation analysis for the international market portfolio and individual developed-country portfolios.

The notebook reconstructs the price index and implied dividends from price and total returns, estimates the valuation model, reports confidence intervals and mean-reversion diagnostics, and compares the country-level results.

Open `international.ipynb` for the executed notebook or `international.html` for the rendered report.
