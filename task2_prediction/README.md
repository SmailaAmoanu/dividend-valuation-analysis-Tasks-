# Task 2 — Out-of-Sample Prediction

The valuation model is estimated using observations through 2000 and evaluated over 2021–2025.

Because `full-data.xlsx` begins in 1927 and the construction uses both first differences and a lagged cumulative term, the effective regression sample is 1929–2000.

The notebook reports the fitted valuation parameters, confidence interval, mean-reversion diagnostics, actual and predicted values for 2021–2025, forecast errors, and residual diagnostics.

Open `task2_valuation.ipynb` for the executed notebook or `task2_valuation.html` for the rendered report.
