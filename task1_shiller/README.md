# Task 1 — Shiller Annual Data

Dividend-based valuation analysis using the annual S&P Composite index and dividend series in `data7.xlsx`.

The analysis covers 1871–2025 and reports the fitted valuation parameters, detrended valuation measure, confidence interval for the trend, mean-reversion test, and residual diagnostics.

Open `task1_shiller.ipynb` for the executed notebook or `task1_shiller.html` for the rendered report.
